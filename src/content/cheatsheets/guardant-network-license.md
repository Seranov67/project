Ім’я реального сервера ліцензій у нотатках замінено на `<license-server>`. Файл конфігурації може містити ідентифікатори клієнта, тому не завантажуйте його повністю до публічного репозиторію. Для конкретного покоління Guardant звіряйте файл, згенерований сервером, і документацію постачальника ПЗ.

## Визначити версію і файл клієнта

> **Ризик: безпечно.** Перегляд конфігурації не змінює ліцензію.

```text
Знайдіть gnclient.ini біля захищеного застосунку або в місці, яке вказав його постачальник.
```

**Параметри:** перевірте точну назву файлу, версію Guardant Net та відповідність клієнта серверу; не копіюйте приватні поля в публічний тикет.

**Перевірка:** застосунок дійсно читає знайдений файл, а не іншу копію конфігурації.

## Звірити адресу сервера

> **Ризик: безпечно.** DNS-перевірка нічого не змінює.

```powershell
Resolve-DnsName <license-server>
```

**Параметри:** у `gnclient.ini` поле `IP_NAME` має вказувати на актуальний hostname або IP сервера; плейсхолдер замінюйте лише локально.

**Перевірка:** адреса відповідає реальному серверу ліцензій у вашій мережі.

## Перевірити доступність порту

> **Ризик: безпечно.** Команда перевіряє TCP-з’єднання; для конкретної версії й режиму Guardant може знадобитися також UDP.

```powershell
Test-NetConnection <license-server> -Port 3186
```

**Параметри:** `3186` — типовий порт ліцензування для певних версій Guardant Net; `3187` — типовий порт повідомлень. Фактичні значення визначає конфігурація сервера.

**Перевірка:** `TcpTestSucceeded` дорівнює `True`; якщо ні, перевірте маршрут, firewall і службу сервера.

## Оновити клієнтський ini з резервною копією

> **Ризик: змінює систему.** Помилка в портах або UUID може повністю зупинити видачу ліцензії.

```ini
[SERVER]
IP_NAME = <license-server>
PORT = 3186
MESSAGE_PORT = 3187
```

**Параметри:** це лише фрагмент, а не готовий повний `gnclient.ini`. Збережіть оригінал і за можливості експортуйте клієнтський файл із вебінтерфейсу сервера Guardant; не підставляйте вигаданий UUID.

**Перевірка:** після перезапуску захищеного застосунку ліцензія знаходиться, а сервер фіксує звернення клієнта.

## Перевірити проблему без широкомовного пошуку

> **Ризик: безпечно.** Діагностика не змінює налаштування клієнта.

```powershell
Resolve-DnsName <license-server>
Test-NetConnection <license-server> -Port 3186
```

**Параметри:** якщо автоматичний пошук сервера вимкнений, клієнт покладається на визначений сервер; широкомовна адреса не замінює коректний `IP_NAME`.

**Перевірка:** DNS і порт доступні, версії клієнта та сервера сумісні. Якщо ні — усуньте саме цю причину до редагування таймаутів.
