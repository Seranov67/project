Розрізняйте попередження про перенаправлення ресурсів і помилку протоколу ліцензування: це різні проблеми. Змінюйте реєстр лише після підтвердження симптомів і з резервною копією.

## Перевірити поточне налаштування діалогу

> **Ризик: безпечно.** Команда лише читає політику RDP-клієнта.

```cmd
reg query "HKLM\Software\Policies\Microsoft\Windows NT\Terminal Services\Client" /v RedirectionWarningDialogVersion
```

**Параметри:** відсутність значення означає поведінку Windows за замовчуванням.

**Перевірка:** зафіксуйте поточне значення і точний текст попередження перед змінами.

## Тимчасово повернути попередній діалог

> **Ризик: змінює систему.** Microsoft описує `1` як тимчасове повернення старої версії діалогу, а не як універсальне вимкнення всіх попереджень. Це знижує видимість нового попередження безпеки.

```cmd
reg add "HKLM\Software\Policies\Microsoft\Windows NT\Terminal Services\Client" /v RedirectionWarningDialogVersion /t REG_DWORD /d 1 /f
```

**Параметри:** потрібен запуск від адміністратора; `/f` не запитує підтвердження. Застосовуйте лише коли новий діалог реально заважає роботі.

**Перевірка:** закрийте й відкрийте `mstsc.exe` та звірте поведінку; заплануйте повернення стандартної політики після усунення причини.

## Повернути стандартну поведінку

> **Ризик: змінює систему.** Видаляється лише конкретне значення, а не вся політика клієнта.

```cmd
reg delete "HKLM\Software\Policies\Microsoft\Windows NT\Terminal Services\Client" /v RedirectionWarningDialogVersion /f
```

**Параметри:** команда потребує адміністратора; використовуйте її тільки якщо значення було додано як локальний тимчасовий обхід, а не задано доменною GPO.

**Перевірка:** `reg query` більше не знаходить значення, а після нового запуску клієнта з’являється стандартний діалог.

## Зберегти кеш ліцензій перед ремонтом

> **Ризик: безпечно.** Експорт створює локальну резервну копію; вона може містити службові дані й не повинна потрапити в публічний репозиторій.

```cmd
reg export "HKLM\Software\Microsoft\MSLicensing" "%USERPROFILE%\Desktop\MSLicensing-backup.reg"
```

**Параметри:** виконуйте тільки на клієнті з помилкою ліцензійного протоколу; якщо ключа немає, перевірте справжній текст помилки й редакцію клієнта.

**Перевірка:** файл резервної копії існує і зберігається лише в захищеному місці.

## Відновити ліцензійний кеш за інструкцією Microsoft

> **Ризик: незворотно.** Видалення `MSLicensing` очищає локальні токени. Робіть це лише для підтвердженої помилки ліцензування після експорту й перевірки доступності сервера ліцензій.

```cmd
reg delete "HKLM\Software\Microsoft\MSLicensing" /f
```

**Параметри:** потрібні права адміністратора. Для першого підключення після очищення запустіть «Підключення до віддаленого робочого столу» від адміністратора, щоб Windows могла відтворити ключ.

**Перевірка:** підключення проходить без помилки протоколу ліцензування, а ключ створюється знову. Якщо ні — перевірте сервер ліцензування, а не повторюйте видалення.
