Починайте з читання поточного стану. Для зміни прав надавайте рівно той доступ, який потрібен процесу або користувачу, і не використовуйте `chmod 777` як універсальне виправлення.

## Побачити режим, власника й час зміни

> **Ризик: безпечно.** `stat` лише читає метадані файлової системи.

```bash
stat --format='mode=%A (%a) owner=%U:%G size=%s modified=%y' <path>
```

**Параметри:** `%A` — символьні права, `%a` — octal-режим, `%U:%G` — власник і група.

**Перевірка:** порівняйте з коротким поданням каталогу.

```bash
ls -ld -- <path>
```

## Встановити точні права символами

> **Ризик: змінює систему.** Помилковий режим може заблокувати доступ сервісу або відкрити дані іншим користувачам.

```bash
chmod u=rw,g=r,o= -- <file>
```

**Параметри:** власник отримує читання й запис, група — лише читання, інші — жодного доступу.

**Перевірка:** очікуваний octal-режим — `640`.

```bash
stat --format='%a %n' -- <file>
```

## Змінити власника й групу

> **Ризик: змінює систему.** Переконайтеся, що цільовий користувач і група існують.

```bash
sudo chown <user>:<group> -- <path>
```

**Параметри:** `--` завершує опції та захищає шлях, який починається з дефіса.

**Перевірка:** команда має показати нові імена без зміни режиму доступу.

```bash
stat --format='%U:%G %a %n' -- <path>
```

## Окремо нормалізувати каталоги й файли

> **Ризик: змінює систему.** Спочатку звузьте `<root>` до конкретного дерева й перегляньте вибірку без `-exec`.

```bash
find <root> -type d -exec chmod 750 {} +
find <root> -type f -exec chmod 640 {} +
```

**Параметри:** каталоги потребують `x` для входу; файлам виконання зазвичай не потрібне. `{} +` передає кілька шляхів одному виклику.

**Перевірка:** знайдіть об’єкти, режим яких відрізняється від політики.

```bash
find <root> -type d ! -perm 750 -print
find <root> -type f ! -perm 640 -print
```

## Створити файл одразу з потрібним режимом

> **Ризик: змінює систему.** `install` створить або замінить цільовий файл.

```bash
install -m 640 -o <user> -g <group> <source> <destination>
```

**Параметри:** `-m` задає режим, `-o` власника, `-g` групу; для власника/групи зазвичай потрібен `sudo`.

**Перевірка:** звірте всі три атрибути однією командою.

```bash
stat --format='%a %U:%G %n' -- <destination>
```

## Задати права для нових файлів у сесії

> **Ризик: змінює поведінку сесії.** `umask` не змінює існуючі файли, але впливає на нові.

```bash
umask 027
```

**Параметри:** маска `027` зазвичай дає `640` для файлів і `750` для каталогів, якщо програма запитує стандартні максимальні права.

**Перевірка:** створіть тимчасовий файл у контрольованому каталозі й видаліть його після перевірки.

```bash
touch ./umask-check && stat --format='%a' ./umask-check && rm ./umask-check
```
