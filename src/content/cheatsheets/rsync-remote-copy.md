У команді з нотаток джерело було на сервері, а призначення — локальний диск. Конкретний hostname, логін і UUID диска замінено плейсхолдерами. Не додавайте `--delete`, якщо не хочете видаляти локальні файли, яких немає на сервері.

## Перевірити джерело й диск призначення

> **Ризик: безпечно.** Команди нічого не копіюють.

```bash
ssh <user>@<server> 'ls -ld /path/to/source'
df -h /path/to/destination
```

**Параметри:** замініть `<user>`, `<server>` і шляхи фактичними значеннями; перевірте, що локальний носій змонтовано й на ньому достатньо місця.

**Перевірка:** SSH відкривається, джерело існує, а локальний шлях належить потрібному диску.

## Зробити пробний запуск

> **Ризик: безпечно.** `--dry-run` показує план без передавання файлів.

```bash
rsync -avzn --itemize-changes <user>@<server>:/path/to/source/ /path/to/destination/
```

**Параметри:** `/` після `source/` означає «вміст теки»; без неї копіюватиметься сама тека. `-n` — лише симуляція.

**Перевірка:** список файлів і напрямок відповідають очікуваному; немає неочікуваних великих або конфіденційних файлів.

## Скопіювати файли

> **Ризик: змінює систему.** Існуючі локальні файли з тим самим шляхом можуть бути оновлені.

```bash
rsync -avz --progress <user>@<server>:/path/to/source/ /path/to/destination/
```

**Параметри:** `-a` зберігає атрибути, `-v` показує файли, `-z` стискає потік, `--progress` показує поступ; не використовуйте `--delete` без окремого плану.

**Перевірка:** команда завершилась з кодом `0`, а кількість і розміри важливих файлів збігаються.

## Продовжити після переривання

> **Ризик: змінює систему.** Повторний запуск синхронізує відсутні або змінені файли на локальному диску.

```bash
rsync -avz --partial --info=progress2 <user>@<server>:/path/to/source/ /path/to/destination/
```

**Параметри:** `--partial` зберігає незавершений файл для продовження, `--info=progress2` показує загальний прогрес.

**Перевірка:** повторний `--dry-run --itemize-changes` не пропонує неочікуваних змін.

## Перевірити дані після копії

> **Ризик: безпечно.** Перевірка контрольних сум читає обидві сторони і може бути повільною на великому архіві.

```bash
rsync -avznc --itemize-changes <user>@<server>:/path/to/source/ /path/to/destination/
```

**Параметри:** `-c` порівнює вміст за контрольними сумами; `-n` нічого не записує.

**Перевірка:** немає файлів, які потрібно повторно скопіювати; якщо є, перевірте зміни на сервері між запусками.
